# 05 Public Bulk Candidate Non-IMGT Audit

Purpose: support Supplementary Table S20 and the sample-level observed-evidence versus graph-guided-imputation audit in public bulk RNA-seq candidate allele reporting.

Implementation:

- `code/experiments/05_public_bulk_candidate_nonimgt/annotate_bulk_evidence_imputation.py`: annotates public bulk candidate allele sites as retained-evidence supported, conflicting, covered-but-not-supported, or graph-imputed. It uses the centralized PanTCR completion logic in `code/pantcr/infer_genotype_bayes.py`.

Evidence interpretation: candidate-defining non-IMGT changes are evaluated from
retained sample-level observations. External database matches such as
VDJ.online are reported as independent annotation support.

Inputs: public bulk summary tables, PanTCR inference CSVs, mutation-observation CSVs, and graph-prior files generated by the public bulk application pipeline under `experiments/01_in_silico_trbv_benchmarks/benchmark_pipelines/04_public_bulk_rnaseq/generated/BULK-1` and `generated/BULK-2`. Override them with `--bulk1-root` and `--bulk2-root` only for auditing a separate full-provenance rerun.

The upstream public-bulk SRA/MiXCR/mutation/graph/inference workflow is
documented in
`experiments/01_in_silico_trbv_benchmarks/benchmark_pipelines/04_public_bulk_rnaseq/README.md`.
Raw reads and large intermediate trees follow that pipeline's `input/` and
`generated/` layout.

## Run

After the public bulk pipeline has generated `BULK-1` and `BULK-2` result
roots, run:

```bash
bash experiments/05_public_bulk_candidate_nonimgt/run_rebuild.sh
```

To audit a separate full-provenance rerun, pass explicit roots:

```bash
bash experiments/05_public_bulk_candidate_nonimgt/run_rebuild.sh \
  --bulk1-root experiments/01_in_silico_trbv_benchmarks/benchmark_pipelines/04_public_bulk_rnaseq/generated/BULK-1 \
  --bulk2-root experiments/01_in_silico_trbv_benchmarks/benchmark_pipelines/04_public_bulk_rnaseq/generated/BULK-2
```

## Outputs And Downstream Use

Rerun outputs are written under `generated/evidence_imputation`. Add
`--write-mature-position-detail` when running
`code/experiments/05_public_bulk_candidate_nonimgt/annotate_bulk_evidence_imputation.py`
to write the full mature-position detail table.
